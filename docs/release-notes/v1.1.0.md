# Release Notes - Versão 1.1.0

Entrega focada em perfil do usuário (edição e avatar), melhorias na experiência de uso (seleção de turma e diálogos de confirmação) e refinamentos na landing page.

## Visão Geral

Esta versão introduz recursos de gerenciamento de perfil (incluindo upload de avatar e campos com DatePicker), aprimora fluxos de seleção/confirmacão com componentes dedicados e traz ajustes na landing page para comunicação mais clara dos planos.

---

## Funcionalidades Principais

### Perfil do Usuário

**Gerenciamento de Perfil com Avatar e DatePicker**

- Página de perfil atualizada (edição de dados pessoais)
- Upload/alteração de avatar
- Campos de data com novo `DatePicker`
- Validação de formulário com `profileSchema`
- Integração com API via `services/profile.js`
- Hook `useProfile` para isolamento da lógica de dados

### Experiência do Usuário

**Seleção de Turma e Diálogo de Confirmação**

- Novo componente `ClassSelectionModal` para escolher turmas com visual e acessibilidade melhores
- Aprimoramentos no `ConfirmationDialog` (mensagens e comportamento)
- Ajustes no `Modal` e `Header` para consistência visual

### Landing Page

**Melhorias de Comunicação e Layout**

- Ajustes em `PricingSection` para descrição e planos
- Refinos no `Header` e na `LandingPage` para navegação

---

## Informações Técnicas

### Dependências

- Ajustes mínimos em `package.json` (alinhamento com novos componentes)

### Requisitos

- Sem mudanças: Node.js 18+, npm/yarn

### Componentes

- Adicionados: `DatePicker`, `ClassSelectionModal`
- Alterados: `Header`, `Modal`, `ConfirmationDialog`, `PricingSection`

### Hooks

- Adicionado: `useProfile`
- Ajustes: hooks de páginas para integrar perfil/landing

### Páginas

- `Shared/Profile.jsx` atualizado para edição de perfil
- `Public/LandingPage.jsx` com refinamentos de conteúdo/UX

### Serviços e Schemas

- `services/profile.js` (novo serviço de perfil)
- `schemas/profileSchema.js` (validação de dados do perfil)

---

## Notas

- Sem breaking changes conhecidos
- Recomenda-se validar fluxos de upload de avatar e datas em ambientes com CORS/armazenamento de arquivos adequadamente configurados
