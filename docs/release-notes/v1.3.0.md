# Release Notes - Versão 1.3.0

Padronização do editor de módulos, validações centralizadas em schemas, melhorias de UX e correções de fluxo.

## Visão Geral

Esta versão padroniza completamente o editor de módulos, centraliza validações em schemas Zod, melhora a experiência do usuário com proteção contra duplo clique e feedback visual, e corrige o fluxo de redirecionamento após criar módulos.

---

## Funcionalidades Principais

### Editor de Módulos

**Validações centralizadas:**

- Schema completo `quizSchema` com validações de questões, alternativas e pontos
- Remoção de validações inline do componente `ModuleEditor`
- Validação de quiz usando `isValid(quizSchema, currentModule.quiz)`

**Proteção contra duplo clique:**

- Verificação de estado `isPending` antes de executar salvamento
- Botão desabilitado durante operação de salvamento
- Feedback visual com texto "Salvando..." durante processo

**Correção de redirecionamento:**

- Após criar/atualizar módulo, redireciona para listagem geral (sem filtro por curso)
- Links "Voltar" sempre mostram listagem geral
- Permite criar módulos sem vínculo obrigatório com curso

**Correção de vínculo com curso:**

- Módulos podem ser criados sem vínculo com curso
- Permite desvincular módulo de curso (passando `courseId: null`)
- `selectedCourseId` usa apenas `linkedCourseIds[0]` se houver, caso contrário `null`

---

## Detalhes Técnicos

### Schemas

**quizSchema.js:**

- `quizQuestionSchema`: Validação completa de questão com texto, opções, pontos e resposta correta
- Validação de mínimo 2 alternativas não vazias
- Validação de resposta correta correspondendo a uma das alternativas
- `quizSchema`: Validação de array de questões com mínimo de 1 pergunta

### Componentes

**ModuleEditor.jsx:**

- Importação de `isValid` e `quizSchema` de schemas
- Validação de quiz usando `quizSchema.safeParse()` antes de salvar
- Estado `isSaving` para controlar botão durante salvamento
- Remoção de lógica de validação inline de quiz
- Simplificação de `hasQuizErrors` usando `isValid(quizSchema, currentModule.quiz)`

### Serviços

**modules.js:**

- Endpoints separados: `addLessons` (POST) e `updateLessons` (PUT)
- Endpoints separados: `createQuiz` (POST) e `updateQuiz` (PUT)
- Ambos endpoints de lessons sempre enviam multipart (mesmo sem arquivos)

---

## Melhorias de UX

### Feedback Visual

- Botão de salvar mostra "Salvando..." durante operação
- Botão desabilitado durante salvamento para evitar duplo clique
- Mensagens de erro mais claras usando validação do schema

### Fluxo de Navegação

- Redirecionamento sempre para listagem geral após salvar módulo
- Links "Voltar" não passam mais `courseId` no state
- Usuário pode criar módulo sem vínculo obrigatório com curso
